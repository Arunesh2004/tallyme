`AuthService` was an empty class (`export class AuthService {}`). `AuthController.login()` directly returned the string `'STUB_ACCESS_TOKEN'` with no user lookup, no password comparison, and no JWT signing.

## Implementation Details

### Login Flow
```
POST /auth/login { email, password }
  → PrismaService.user.findUnique({ where: { email }, include: { role: { include: { permissions } } } })
  → bcrypt.compare(password, user.passwordHash)
  → jwtService.signAsync({ sub, email, roles, permissions, tenantId })
  → prisma.session.create({ userId, refreshToken (random 64 bytes hex), expiresAt (7 days) })
  → Response: { accessToken: JWT, user: { id, email, role, permissions } }
  → HttpOnly Cookie: refresh_token
```

### Refresh Flow
```
POST /auth/refresh (cookie: refresh_token)
  → prisma.session.findUnique({ where: { refreshToken } })
  → Validate: not revoked, not expired, user.isActive
  → prisma.session.update({ isRevoked: true }) [rotation — old token invalidated]
  → jwtService.signAsync(new payload)
  → prisma.session.create(new refresh token)
  → Response: new accessToken + new HttpOnly refresh_token cookie
```

### Logout Flow
```
POST /auth/logout (Bearer JWT required)
  → prisma.session.updateMany({ where: { userId, refreshToken }, data: { isRevoked: true } })
  → res.clearCookie('refresh_token')
```

### Security Properties
- Passwords hashed with bcrypt at **12 salt rounds** (OWASP recommended minimum)
- JWT signed with configurable secret from `security.jwtSecret` env variable
- JWT expiry configurable via `security.jwtExpiry` (default: `15m`)
- Refresh tokens are **opaque random bytes** (64 bytes = 128 hex chars), not JWTs
- Refresh token **rotation**: old session revoked on every refresh
- Refresh tokens stored as **plaintext** in DB (SHA-256 hashing would be stronger, noted for future hardening)
